## 3、网站主题色

### 推荐：**暗色主题为默认**

Scavland 的视觉关键词非常明确：

**Post-Apocalyptic + Soviet + Mist + Radiation + Ruins + Pixel Art**

因此不建议用常见游戏 Wiki 的亮绿色、蓝色或紫色作为大面积主色。

我建议：

* **默认 Dark Mode**
* 主色：**Mutated / Toxic Green**
* 辅色：灰黑、锈色、暗黄
* CTA 可以使用偏荧光的绿色
* 背景尽量接近煤黑/深灰，而不是纯黑

绿色与游戏里的 **Mist / Radiation / Toxic atmosphere** 有天然关联，同时不会过度模仿 S.T.A.L.K.E.R. 的视觉体系。

```css
/* 导航页主题色 - 亮色主题 */
--nav-theme: 148 52% 42%;  /* wasteland green */
--nav-theme-light: 148 52% 52%;  /* 更浅的绿色 */

/* 导航页主题色 - 暗色主题 */
--nav-theme: 148 52% 42%;  /* toxic wasteland green */
--nav-theme-light: 148 52% 52%;  /* 更亮的绿色 */
```

**默认：Dark Theme**

建议 UI 基础背景：

* 页面背景：`#0D100F` 附近
* Card：`#151A18`
* Border：低饱和灰绿
* 主 CTA：`#3FA66B` 附近
* Warning：锈橙 / 暗黄色
* Radiation / Mist 提示：荧光绿

整体应该让用户第一眼感觉是：

> **“我正在进入一个危险的废土数据库。”**

而不是普通 RPG Wiki。

## 4、多语言

### 先说结论

按照**玩家市场 + Steam 已支持语言 + Scavland 本身的本地化覆盖情况 + 潜在搜索流量**，我建议网站最多做这 4 门：

| 优先级   | 语言           | 本地化主题名               | 建议   |
| ----- | ------------ | -------------------- | ---- |
| **1** | 🇺🇸 English | **Scavland Wiki**    | 必做   |
| **2** | 🇩🇪 German  | **Scavland Wiki**    | 第二优先 |
| **3** | 🇪🇸 Spanish | **Wiki de Scavland** | 第三优先 |
| **4** | 🇷🇺 Russian | **Вики Scavland**    | 第四优先 |

### ① English — 第一优先级

**主题名：Scavland Wiki**

这是绝对的主站语言。

原因：

* 官方内容首先以英语发布
* Steam 英语支持
* 官方 YouTube、Discord、Patreon 均以英语为核心
* 全球搜索覆盖最大
* `Scavland wiki`、`Scavland guide`、`Scavland weapons`、`Scavland map` 等核心词应首先建立英文页面

### 为什么没有把 Japanese / French / Chinese 放进前四？

并不是这些语言没有价值。

实际上 Steam 当前支持 **11 种语言**，包括 French、Italian、German、Spanish、Japanese、Brazilian Portuguese、Russian、Simplified Chinese、Latin American Spanish 和 Ukrainian。([Steam商店][1])

但如果你的目标是**SEO 建站初期最大化自然搜索覆盖，而不是单纯跟随 Steam localization list**，我会把：

**English → German → Spanish → Russian**

作为第一阶段。

尤其是 Russian 与 Scavland 的 Soviet / STALKER / Metro 题材天然契合；German 和 Spanish 则具有更大的泛欧洲/西语游戏搜索覆盖。

**第二阶段**再考虑：

1. Japanese
2. French
3. Portuguese-Brazil
4. Simplified Chinese
5. Ukrainian

另外，官方团队此前确实公开招募过 **Spanish、French、German、Russian、Ukrainian、Japanese、Italian、Simplified Chinese** 本地化人员，说明这些语言并非凭空推测，而是开发团队实际考虑过的本地化方向。([LinkedIn][7])

## 最终建站定位建议

Scavland 这个词目前非常适合做一个**“新游戏首发型 Wiki”**，而不是传统成熟游戏百科。
